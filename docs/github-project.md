# GitHub Projects: referencia histórica

El tablero `Sportues — M3 Framework` nunca se creó. Este repositorio ya no usa GitHub Projects para administrar tareas; el backlog canónico está en [`.tasks/`](../.tasks/README.md) y se versiona con Git.

La antigua propuesta de tablero se conserva en el historial del repositorio, pero sus instrucciones de creación, campos y automatizaciones ya no forman parte del flujo vigente. No se consulta ni modifica ningún Project remoto.

Las referencias `#N` de documentos previos son identificadores históricos de GitHub Issues. Solo se copian al campo `github_issue` cuando el equipo migra explícitamente un Issue usando información local comprobable; los datos que falten quedan pendientes.

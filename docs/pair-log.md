# Pair programming log

## Acuerdo de trabajo

- Ambos integrantes participan en frontend, backend, pruebas y documentación.
- El rol de **driver** escribe el código; el de **navigator** revisa, pregunta y guía.
- Se intercambian roles cada 20 minutos.
- Cada sesión real se registra al terminar, incluyendo enlaces a la rama o pull request.

## Objetivo

Crear `docs/roadmap.md` con las fases del resto de M3 y el Final, cada checkbox enlazado a un issue.

## Criterios de aceptación

**Criterio 1**
- **Given** existe `docs/roadmap.md`
- **When** se abre
- **Then** tiene fases con fechas de los checkpoints y cada checkbox enlaza a un issue real

**Criterio 2**
- **Given** un PR termina un ítem del roadmap
- **When** se revisa el PR
- **Then** el checkbox está marcado en ese mismo PR

## Fuera de alcance

Trabajo de producto de M3 (tiene sus propios issues).

## Notas

Parte del framework de equipo (Team Implementing Framework).

## Definition of Ready

- [ ] Tiene criterios de aceptación (Given / When / Then)
- [ ] Tiene responsable asignado (**asignarlo antes de mover a Ready**)
- [ ] No tiene bloqueos abiertos

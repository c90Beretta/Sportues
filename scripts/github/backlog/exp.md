## Objetivo

Preparar el experimento vibe vs engineered: elegir un issue mediano real y guardar las predicciones antes de correr nada.

## Criterios de aceptación

**Criterio 1**
- **Given** un issue de M3 de tamaño mediano
- **When** se elige
- **Then** sus criterios de aceptación están escritos antes de cualquier ejecución

**Criterio 2**
- **Given** cada integrante
- **When** escribe sus predicciones sin IA
- **Then** quedan en `docs/experiment.md` con fecha anterior a la Run A

## Fuera de alcance

Trabajo de producto de M3 (tiene sus propios issues).

## Notas

Parte del framework de equipo (Team Implementing Framework).

## Definition of Ready

- [ ] Tiene criterios de aceptación (Given / When / Then)
- [ ] Tiene responsable asignado (**asignarlo antes de mover a Ready**)

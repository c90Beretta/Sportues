# Fuentes históricas del bootstrap remoto

Estos archivos son copias locales de contenido que se preparó para GitHub Issues. Se conservan como evidencia y posibles fuentes para una migración manual, pero no son el backlog vigente ni se sincronizan con GitHub.

El bootstrap `scripts/github/bootstrap-github.sh` está retirado. No ejecutes comandos de GitHub para consultar, crear, asignar o cerrar esos Issues. Las tareas vigentes están en [`.tasks/issues/`](../../../.tasks/issues/) y el proceso de migración sin API está en [`.tasks/README.md`](../../../.tasks/README.md).
